# Find-it-near-me-
 Find It Near Me is a Nigerian service-discovery and property-listing platform designed to connect people with trusted local service providers, skilled workers, house agents, and property owners in their communities.

The platform aims to make it easier for Nigerians to find the services and accommodation they need without wasting time searching across multiple social media groups or relying entirely on word of mouth.

## 🚀 Key Features

### 1. Local Service Marketplace
Users can discover skilled professionals and businesses, including plumbers, electricians, carpenters, mechanics, cleaners, tailors, hairdressers, painters, and other service providers.

### 2. House Search and Property Listings
House agents can list properties for rent or sale, including prices, descriptions, property types, bedroom counts, and locations. Customers can search for houses using keywords, price ranges, property types, and location filters.

### 3. Location-Based Discovery
The platform is designed to support all 36 Nigerian states and the Federal Capital Territory (FCT), with Local Government Area (LGA) selection to help users find nearby services and properties. Optional GPS location sharing can help identify a property's location on a map.

### 4. Customer and Service Provider Accounts
The project includes separate account experiences for customers and service providers, with planned dashboards for managing listings, payments, and access.

### 5. Chat Between Customers and Agents
A messaging feature is planned to help customers ask questions, confirm availability, discuss property details, and arrange inspections with house agents.

### 6. Payment and Premium Access Model
The proposed business model includes a one-time ₦1,000 registration payment for service providers to publish services and a ₦100 payment for customers to unlock service-provider contact details for 24 hours. Paystack integration is planned for secure payment processing and automated access expiry.

## 🛠️ Technology and Development

The project uses HTML, CSS, and JavaScript for its frontend prototype, with Supabase planned for authentication and database storage and a secure Node.js backend for payment verification.

## 🎯 Mission

Our mission is to make finding local services and affordable accommodation easier, faster, and more accessible throughout Nigeria.

**Find It Near Me — Find a service. Find a house. Find it near you.**

*Note: This project is under development. Some features are prototypes and require backend integration before production use.*
